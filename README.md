# Portfolio

Personal site for Brijesh Nanda B Y, served at https://brijesh-nanda-by.github.io/Portfolio/.

Built with React, TypeScript, Vite and Tailwind CSS v4.

## Editing content

All text (profile, projects, publications, experience, skills, education) is in
[`src/data/portfolio.ts`](src/data/portfolio.ts). The résumé download is served from `public/resume.pdf`.

## Scripts

```sh
npm run dev        # local dev server
npm run build      # production build to dist/
npm run lint
npm run deploy     # publish dist/ to gh-pages
```
